# Midnight Chill Player

A sound player for deep relaxation and focus in the late night. Built with HTML, CSS, and JavaScript.

## what it does:

- Ambient Soundscapes
- Interactive Playback Controls
- Progress Tracking

## How to run:

Just open the file "index.html" in any browser, or simply click the demo link.

## Inspiration:

I made this project because I often need some relaxation for my mind in the late night while studying or working on smth.
